## 関数宣言

```javascript
function 関数名(仮引数1, 仮引数2) {
  //処理
  return 関数の返り値;
}
//関数呼び出し
const 関数の結果 = 関数名(引数1, 引数2)
console.log(関数の結果)    //関数の返り値
```

- 関数が何も値を返す必要がない場合、`return`文自体を省略できる（`undefined`を返す）

## 関数の引数

### 引数の個数
- 関数に定義した仮引数の個数と実際に呼び出したときの引数の個数が異なっても、関数を卯呼び出すことができる
- 呼び出し時の引数が少ないとき：余った仮引数には`undefined`が代入される
- 呼び出し時の引数が多いとき：溢れた引数は無視される

### デフォルト引数

```javascript
function 関数名(仮引数1 = デフォルト値1, 仮引数2 = デフォルト値2){

}
```
- 仮引数に対応する引数が渡されていない場合に、デフォルトで代入される値を指定できる

## 可変長引数

### 残余引数

- Rest Parameters（残余引数）
- 仮引数名の前に`...`をつけた仮引数
- 関数に渡された値が配列として代入される
- 末尾の仮引数として定義することで、通常の仮引数と合わせることができる

```javascript
function fn(...args) {
  console.log(args);
}
fn("a", "b", "c");    //["a", "b", "c"]
```

#### Spread構文

- 配列の前に`...`をつけた構文のこと
- 配列を展開して関数の引数に渡す
- `fn(...array);`

### arguments

- `arguments`という関数の中でのみ参照できる特殊な変数を使って、可変超引数を扱うことができる
- `arguments`は関数に渡された引数の値が全て入ったArray-likeなオブジェクトで、配列のようにインデックスで要素へアクセスできるが、Arrayのメソッドは利用できない
- 仮引数が定義されていなくても、関数の内部では`arguments`という変数で、実際に渡された引数を参照できる

```javascript
function fn() {
  console.log(arguments[0]);
  console.log(arguments[1]);
  console.log(arguments[2])
}
fn("a", "b", "c");
```

- 以下のような問題点から、残余引数が利用できる環境では`arguments`は使わないほうが良い
  - Arrow Functionでは利用できない
  - Arrayのメソッドを利用できない
  - 関数が可変長引数を受け付けるのかを、仮引数だけを見て判断できない
