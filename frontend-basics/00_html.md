## 記述方法

### DOCTYPE宣言

- HTML文書を送る際に必須の前置き（プリアンブル）
- HTMLのバージョンを示す
- 現在のDOCTYPE宣言：`<!DOCTYPE html>

### HTML要素

- `head`要素：文書の情報の集まり
- `body`要素：コンテンツの集まり
- コメント：`<!-- -->`

### テンプレート

```html
<!DOCTYPE html>
<html lang="ja">
  <head></head>
  <body></body>
<html>
```

## 情報の要素

- `title`要素：検索結果のタイトル、ブラウザのタブの表示
  
  ```html
  <title>〜</title>
  ```

- `style`要素：CSSを文章に埋め込む

  ```html
  <style>〜</style>
  ```

- `script`要素：動的なスクリプトを含む

  ```html
  <script>〜</script>
  ```

- 文書の説明：検索結果の説明文としてアピールできる

  ```html
  <meta name="description" content="内容">
  ```

- スマホ対応：表示領域（viewport）の調整
  
  ```html
  <meta name="viewport" content="device-width">
  ```

  参照：[viewport](07_unique_css.md#viewport)

- オープングラフ：WebページをSNSでシェアした際の表示方法を設定できる

  ```html
  <meta property="og: " content=" ">
  ```
  - og: `url`, `type`, `title`, `description`, `image`

## ブロック型の要素

- 見出し・段落・表など、文書を構成する基本となる要素
- 現在のHTMLのルールでは消えている定義

### ブロック型の要素

- `div`要素：意味を持たないブロック型の要素（デザイン目的）
- `header`要素：前置きのグループ
- `nav`要素：主要な他のページへのリンク（メインリンク）
- `main`要素：文書の主要なコンテンツ
- `footer`要素：後おきのグループ
- `h1`要素：見出し（h1〜h6）
- `section`要素：文章の一般的セクション
- `p`要素：段落

<br>

- `article`要素：文書等の中で完全もしくは自己完結した構造
- `aside`要素：
  - 他の要素と若干関連するが、独立したセクション
  - サイドバーによく使われる
- `blockquote`要素：別のソースから引用されているセクション（段落での引用）
- `details`要素：表示・非表示を示す（コンテンツを折りたたむ）
  - `summary`要素：まとめ・キャプション・凡例

  ```html
  <details>
    <summary>
    </summary>
  </details>
  ```

### 箇条書きの要素

1. 順番のない箇条書き

  ```html
  <ul>
    <li></li>
    <li></li>
  </ul>
  ```

  - `ul`要素：順番のない箇条書き
  - `li`要素：箇条書きの一つの項目
  - 項目の先頭に`・`が表示される

2. 順番のある箇条書き

  ```html
  <ol>
    <li></li>
    <li></li>
  </ol>
  ```

  - `ol`要素：順番のある箇条書き
  - 項目の先頭に数字が表示される

  <br>

  - `reversed`属性：逆順
  - `type`属性：種類を変える
  - `start`属性：開始番号を変える

3. 説明の箇条書き

  ```html
  <dl>
    <dt></dt>
    <dd></dd>
    <dt></dt>
    <dd></dd>
  </dl>
  ```

  - `dl`要素：説明のグループ
  - `dt`要素：説明する対象
  - `dd`要素：説明

<br>

## インライン型の要素

- 文書の一部として含むことのできる要素
- HTMLの文書内で、テキストの一部や他の要素の中に配置される
- 横に伸びない
- 現在のHTMLルールでは消えている定義

### インライン型の要素

- `small`要素：
  - 免責事項、警告、法的制約、または著作権
  - 通常はfooter内に書く
- `em`要素：要素のコンテンツの強調
- `strong`要素：強力な重要性、深刻性、または緊急性
- `q`要素：インライン型尿素の引用（行内での引用）
- `span`要素：何の意味もない要素（スタイルに利用）
- `br`要素：改行（閉じタグなし）
- `wbr`要素：
  - 改行の機会
  - HTML内の英単語は途中で切れず、長すぎるとあぶれる
  - ブラウザの幅に応じて切ってもよい場所を指定する
- `code`要素：コンピュータコードであることを示す
  - `pre`要素：整形済みテキストのブロック型の要素（改行やタブが有効になる）
- `sup`要素：上付き文字
- `sub`要素：下付き文字
- `ruby`要素：ルビ注釈（ふりがな）
  - `rt`要素：ルビのテキスト
- `mark`要素：読者の注意を喚起するため、テキストの一部に追加されたハイライト

### 画像の要素

`img`要素：画像の要素

<br>

- `src`属性：ファイルの所在・出典
- `alt`属性
  - 画像が表示されなかった場合の代替表示
  - 検索エンジンに画像の内容を伝えることができる
  - 音声読み上げソフトでの読み上げテキストになる

### リンクの要素

`a`要素：リンクの要素

<br>

``` html
<p><a href="https://example.com">サイト</a>へアクセス</p>
```

- `target`属性：リンク先のWebページの開き方
  - `_blank`：新規ウィンドウ（タブ）で開く
  - `_self`：自分自身のウィンドウ（ラブ）で開く
- ページ内リンク：hrefにリンク先のid名を指定する
  - リンク元

    ```html
    <p><a href="#goTo">goTo</a>に飛ぶ<p>
    ```

  - リンク先

    ```html
    <h2 id="goTo">goTo</h2>
    ```

<br>

- `nav`要素

### 入力の要素

1. `input`要素：1行入力の要素

  ```html
  <p>お名前：<input type="text"></p>
  ```

  - `type`属性：種類
    - `text`：テキストの入力
    - `range`：スライダの入力
    - `date`：カレンダーの入力
    - `color`：色の入力
    - `radio`：ラジオボタン
      ```html
      <input type="radio" name="answer">
      ```
  - `label`：input要素と文字列を紐づけする要素

2. `select`要素：選択入力の要素

  ```html
  <p>サイズ
    <select>
      <option>S</option>
      <option>M</option>
      <option>L</option>
    </select>
  </p>
  ```

3. `textarea`要素：複数行の入力の要素

  ```html
  <p>感想：<textarea></textarea></p>

4. `button`要素：ボタンの要素（入力の要素ではないが、密接に関係する）

### マルチメディアの要素

1. `audio`要素：音の要素

  ```html
  <p><audio src=" " controls loop></audio></p>
  ```

  - `controls`属性：コントローラを表示
  - `loop`属性：繰り返し
  - `autoplay`属性：自動実行（標準では無効）

2. `video`要素：動画（映像＋音）の要素

  ```html
  <p><video src=" " controls loop></video></p>
  ```

  - `controls`属性：コントローラを表示
  - `loop`：繰り返し
  - `autoplay`：自動実行
  - `muted`：音を消す
