## 情報の要素

- `title`要素：検索結果のタイトル、ブラウザのタブの表示
  
  ```html
  <title>〜</title>
  ```

- `style`要素：CSSを文章に埋め込む

  ```html
  <style>〜</style>
  ```

- `script`要素：動的なスクリプトを含む

  ```html
  <script>〜</script>
  ```

<br>

## ブロック型の要素

- `div`要素：意味を持たないブロック型の要素（デザイン目的）
- `header`要素：前置きのグループ
- `nav`要素：主要な他のページへのリンク（メインリンク）
- `main`要素：文書の主要なコンテンツ
- `footer`要素：後おきのグループ
- `h1`要素：見出し（h1〜h6）
- `section`要素：文章の一般的セクション
- `p`要素：段落

<br>

- `article`要素：文書等の中で完全もしくは自己完結した構造
- `aside`要素：他の要素と若干関連するが、独立したセクション（サイドバーによく使われる）
- `blockquote`要素：別のソースから引用されているセクション（段落）

<br>
コンテンツを折りたたむ

- `details`要素：表示・非表示を示す
- `summary`要素：まとめ・キャプション・凡例

  ```html
  <details>
    <summary>
    </summary>
  </details>
  ```

<br>

## 箇条書きの要素

### 順番のない箇条書き

```html
<ul>
  <li></li>
  <li></li>
</ul>
```

- `ul`要素：順番のない箇条書き
- `li`要素：箇条書きの一つの項目
- 項目の先頭に`・`が表示される

### 順番のある箇条書き

```html
<ol>
  <li></li>
  <li></li>
</ol>
```

- `ol`要素：順番のある箇条書き
- 項目の先頭に数字が表示される

<br>

- `reversed`属性：逆順
- `type`属性：種類を変える
- `start`属性：開始番号を変える

### 説明の箇条書き

```html
<dl>
  <dt></dt>
  <dd></dd>
  <dt></dt>
  <dd></dd>
</dl>
```

- `dl`要素：説明のグループ
- `dt`要素：説明する対象
- `dd`要素：説明
