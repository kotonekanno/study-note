## 記述例

```
sequenceDiagram
    participant ユーザー
    participant ブラウザ
    participant データベース
    ユーザー->>ブラウザ:ログインする
    ブラウザ->>データベース:会員情報を照合
    データベース-->>ブラウザ:結果

    alt 認証成功
        ブラウザ->>ユーザー:ダッシュボードを表示
    else　認証失敗
        ブラウザ->>ユーザー:エラーメッセージを返す
    end
```

## 1. 図形の種類を設定

```
sequenceDiagram
```

## 2. オブジェクト名の設定

```
participant <object>
```

登場するオブジェクト名を設定

## 3. メッセージ

- `->`：矢印のない実線
- `-->`：矢印のない点線
- `->>`：矢印付きの実線
- `-->>`：矢印付きの点線
- `-x`：最後に+がある実線
- `--x`：最後に+がある点線
- `-)`：開いた矢印のある実線
- `--)`：開いた矢印のある点線

## 4. その他

- 分岐処理：`alt`/`else`/`end`
- 条件指定：`opt`/`end`
- ループ：`loop`/`end`
- 背景色：`rect rgba(r, g, b, a)`/`end`
