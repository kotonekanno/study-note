## 継承

```java
class 子クラス extends 親クラス {}
```

- 既存クラスの構造・振る舞いを引き継いで、新しいクラスを定義すること
- サブクラスがスーパークラスの機能を受け継ぐ
  - 親クラス（スーパークラス、ベースクラス）
  - 子クラス（サブクラス）
- is-a関係（子クラスは親クラスの一種である）

### 補足

- 子クラスは親クラスの`private`フィールド／メソッドにはアクセスできない
- サブクラスが生成される前、子クラスのコンストラクタの前に親クラスのコンストラクタが実行される

- リストを作ってサブクラスのインスタンスを集約することができる
  ```java
  AbstractClass a[] = new AbstractClass[2];
  a[0] = new SubClass1();
  a[1] = new SubClass2();
  ```

### 特徴

#### メンバの継承範囲

- `public`：継承される
- `protected`：継承される
- `package-private`（デフォルト）：継承される（同一パッケージ）
- `private`：継承されない（存在するが、直接アクセスできない）

#### 単一継承

- 子クラスに対し親クラスが1つしか存在しないこと
- Javaは単一継承

### superキーワード

- `super`：親クラスを指す指標

<!-- omit in toc -->
#### 用途

- 親のメソッド呼び出し：`super.method();`
- 親コンストラクタ呼び出し：`super(引数);`
  - コンストラクタの先頭でのみ使用可能

### オーバーライド

- 親クラスのメソッドを子クラスで再定義すること
- その親クラスのメソッドと同じ、メソッド名・引数・戻り値を持つ

```java
@Override
戻り値型 メソッド名(引数) {}
```
- `@Override`：
  - 本当にオーバーライドになっているか検証
  - 書くのが原則（安全）


## ポリモーフィズム（多態性）

- 同じ型として扱っても、振る舞いが異なること

```java
Animal a = new Dog();
a.speak();     // Dogのspeak()が呼ばれる
```

### 動的ディスパッチ

実行時に、実体の方に応じて呼ばれるメソッドが決まる仕組み
- 変数の型：`Animal`
- 実体の型：`Dog`
- 呼ばれるメソッド：`Dog`のメソッド


## キャスト

### アップキャスト

- 子→親に型を変えること
- 安全
- 常に可能
- 明示キャスト不要

### ダウンキャスト

- 親→子に型を変えること
- 明示的なキャストが必要
- 安全性を保証できない
- 実行時チェックが必要

```java
Dog d = (Dog) a;  // 実体がDogでないとエラー
```


### instanceof演算子

- 実体の型を実行時に判定

```java
if (a instanceof Dog) {
  Dog d = (Dog) a;
}
```
