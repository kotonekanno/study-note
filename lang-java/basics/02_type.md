## 型一覧

### プリミティブ型（基本型）

1. `byte`：整数（8ビット）
2. `short`：整数（16ビット）
3. `int`：整数（32ビット）
4. `long`：整数（64ビット）
5. `float`：小数（32ビット）
6. `double`：小数（64ビット）
7. `char`：1文字（16ビット）
8. `boolean`：true / false（1ビット）

### オブジェクト型（参照型）

- プリミティブ型以外全て
- 例：`String`, `int[]`
- 特徴
  - 実体：ヒープ上に存在する
  - 変数：実体への参照（アドレスのようなもの）
  - `null`：何も参照していない状態

## 型変換（キャスト）

### 暗黙的型変換

- 安全
- 例
  ```java
  int i = 10;
  double d = i;
  ```

### 明示的型変換（キャスト）

- 例
  ```java
  double d = 3.14;
  int i = (int) d;
  ```

## メモリでの扱い

- プリミティブ型：値そのものがコピーされる
- 参照型：参照（同じ実体）を共有
