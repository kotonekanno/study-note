## 概要

- クラス：データ（状態）と処理（振る舞い）をひとまとめにした型
- オブジェクト（インスタンス）：クラスを元に生成された実体
- フィールド：オブジェクトが保持するデータ
  - クラス内で宣言
  - 各インスタンスごとに独立

### クラス定義

```java
[アクセス修飾子] class クラス名 {
  フィールド定義;
  コンストラクタ;
  メソッド定義;
}
```


## コンストラクタ

- オブジェクト生成時に自動で呼ばれる特殊なメソッド
- `return`型を記述しない
- クラスと同じ名前のメソッド
- オーバーローディング可能

### 種類

1. デフォルトコンストラクタ
   - 引数なし
2. 引数月コンストラクタ
   - デフォルトコンストラクタは自動で作られない
   - `new`のときに引数を与えないとエラーになる

### 目的

- インスタンス生成時に初期値を入れる
- 必須パラメータを受け取らせる
- インスタンスと同時に処理を行う

### プログラム例

```java
class Person {
  String name;
  int age;

  Person(String name, int age) {
    this.name = name;
    this.age = age;
  }
}
```

### 補足

- `this()`：コンストラクタの中で用いることで、対応する引数付きコンストラクタを呼び出すことができる


## thisキーワード

- `this`：現在のインスタンスを表す指標
- 用途：
  - フィールドと引数の区別
  - 他のコンストラクタの呼び出し


## カプセル化

- 慣例として、フィールドを`private`で隠蔽し、外部からアクセスするメソッドを介して値の変更・取得を行う

### セッター

- `private`で隠蔽されたフィールドに値を書き込むメソッド
- 通常、フィールドとセッターのローカル変数の名前を同じにする

```java
void setA(int a) { this.a = a; }
```

### ゲッター

- `private`で隠蔽された値を取得するメソッド

```java
int getA() { return this.a; }
```


## その他

### ガーベージコレクタ

- `new`で生成され、メモリに蓄積されたインスタンスを消去する
- 基本的に自信の判断で呼び出される
- `System.gc()`：
  - ガーベージコレクタの起動を促す（必ず起動されるわけではない）
  - この処理を行うことで、適切なタイミングで呼び出されることが期待される

### staticフィールド／メソッド

- フィールド／メソッドを定義する時、`static`修飾子を付けることで、インスタンスを生成しなくても利用できる
- `ClassName.field` / `ClassName.method()`で呼び出す
- インスタンスからも呼び出すことができる（非推奨）

<br>

- `static`フィールド：
  - クラス全体で共有
  - インスタンスごとではない
- `static`メソッド：インスタンスに依存しない処理
