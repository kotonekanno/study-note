## メソッド／フィールド

- **メソッド**：クラス内で定義された関数（処理）のこと
  1. 関数
  2. メンバメソッド
- **フィールド**：クラス内で定義された変数（データ）のこと
  1. メンバ変数
  2. クラス変数（staticな場合）
  3. インスタンス変数（staticでない場合）

## mainメソッド

```java
public class MainClass{
  public static void main(String[] args){
    // 処理
  }
}
```


## パッケージ

- クラスやインターフェースを論理的にまとめる名前空間
- パッケージ宣言
  ```java
  package パッケージ名;
  ```

### import文

他パッケージの型を省略名で使うための宣言

- 単一import
  ```java
  import java.util.List;
  ```
- ワイルドカードimport
  ```java
  import java.util.*;
  ```

### 完全修飾名

- FQCN（Fully Qualified Class Name）
- パッケージ + クラス名
- importしない場合は常にこれを書く


## アクセス修飾子

クラス・メンバの可視範囲を制御する文法

### 種類

1. `public`
   - 同一クラス
   - 同一パッケージ
   - サブクラス
   - 他
2. `protected`
   - 同一クラス
   - 同一パッケージ
   - サブクラス　のみ
3. `package-private`（なし）
   - 同一クラス
   - 同一パッケージ　のみ
4. `private`
   - 同一クラス　のみ

### メソッド／フィールド

- `public`：どこからでも呼び出せる
- デフォルト：同じパッケージ内からのみ呼び出せる
- `protected`：同じパッケージ化、別のパッケージのサブクラスからのみ呼び出せる
- `private`：同じクラス内からのみ呼び出せる

### クラス

- `public`：他のパッケージからもアクセスできる
- デフォルト：同じパッケージ内からのみ呼び出せる

### `final`修飾子

- 変更不可を表す修飾子
- 対象
  - クラス：継承不可
  - メソッド：オーバーライド不可
  - 変数：再代入不可


## キャスト

- 変数の型を一時的に別の型として扱うこと

1. 数値型のキャスト：中身が実際に変換され、メモリ上でも書き換わる
2. オブジェクト型（参照型）のキャスト：中身はそのままで、見えるメソッドの範囲が変わる

### アップキャスト／ダウンキャスト

1. アップキャスト（Upcasting）：子→親に型を変えること
   - 自動的に行われる
   - 安全
2. ダウンキャスト（Downcasting）：親→子に型を変えること
   - 明示的なキャストが必要
   - 安全性を保証できない
