### 目次


## 用語

- **メソッド**：クラス内で定義された関数（処理）のこと
  1. 関数
  2. メンバメソッド
- **フィールド**：クラス内で定義された変数（データ）のこと
  1. メンバ変数
  2. クラス変数（staticな場合）
  3. インスタンス変数（staticでない場合）

## mainメソッド

```java
public class メインクラス名{
  public static void main(String[] args){
    // 処理
  }
}
```

- ファイル名とクラス名は一致している必要がある
