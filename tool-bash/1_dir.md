## ディレクトリを調べる

### パスを調べる

```bash
pwd
```

- カレントディレクトリの絶対パスを表示する
- print working directory

### 一覧を調べる

```bash
ls [-option] [dir/file]
```

- カレントディレクトリのファイル、ディレクトリの一覧を表示する
- list

<!-- omit in toc -->
#### オプション

- `-a`：隠しファイルも含むすべてのファイルを表示
- `-l`：詳細情報を表示

<!-- omit in toc -->
#### 詳細情報

例：`drwxr-xr-x 5 root root 4096 23:30`

- `drwxr-xr-x`：モード
- `5`：ハードリンク数（ファイル）、サブディレクトリ数（ディレクトリ）
- `root`（1つ目）：所有者
- `root`（2つ目）：グループ
- `4096`：サイズ
- `23:30`：更新時間

### ディレクトリの変更

```bash
cd <dir/>
```

- カレントディレクトリを変更する
- change directory

<br>

1. `cd` / `cd ~`：自分のホームディレクトリへの移動
2. `cd /`：rootディレクト医への移動
3. `cd ..`：一つ上位階層への移動

### コマンドのフルパス表示

```bash
which [-option] <command>
```

- 指定されたコマンドのフルパスを表示する

<!-- omit in toc -->
#### オプション

- `-a`：対象コマンドが実行可能な全てのパスを表示する


## ディレクトリを管理する

### ディレクトリノ作成

```bash
mkdir [-option] <dir>
```

- 新しいディレクトリを作成する
- make directory

<!-- omit in toc -->
#### オプション

- `-p`：同時にサブディレクトリを作成する
- `-m`：同時にアクセス権を指定する

### ディレクトリの削除

```bash
rmdir [-option] <dir>
```

- 既存ディレクトリを削除する
- remove directory

### コピー

```bash
cp [-option] <original_dir/file> <new_dir/file>
```

- ファイルやディレクトリをコピーする
- copy

<!-- omit in toc -->
#### オプション

- `-i`：上書きする前に確認する
  - `y`：上書きする
  - `n`：上書きしない
- `-n`：存在するファイルを上書きしない
- `-f`：強制的に上書きする
- `-b`：上書きするファイルのバックアップを作る
- `-R` / `-r`：コピー元がディレクトリの場合、再帰的にコピーする

### 移動／名称の変更

```bash
mv [-option] <old_dir/file> <new_dir/file>
```

- ファイルやディレクトリの名前・場所を変更する
- move

<!-- omit in toc -->
#### オプション

- `-i`：上書きする前に確認する
- `-n`：存在するファイルを上書きしない
- `-f`：強制的に上書きする
- `-b`：上書きするファイルのバックアップを作る

### ファイル、ディレクトリの削除

```bash
rm [-option] <dir/file>
```

- ファイルやディレクトリを削除する
- remove

<!-- omit in toc -->
#### オプション

- `-i`：ファイルを削除する前に確認する
- `-f`：メッセージ無しでファイルを削除する
- `-R` / `-r`：ディレクトリを削除する

## ファイルを管理する

### ファイルの日付を更新

```bash
touch [--option] <dir/file>
```

- 内容を変更せずに、ファイルやディレクトリの更新日時を変更する

<!-- omit in toc -->
#### オプション

- `-t <YYYYMMDDHHmm.ss>`：指定した日時で変更数r

<!-- omit in toc -->
#### ヘルパーとバージョン情報

- `--help`：`touch`の使い方を調べる
- `--version`：`touch`のバージョンを調べる

### ファイルの内容を閲覧1

```bash
less <file>
```

- テキストファイルの内容を一画面ずつ表示する
- 操作方法：スクロールで操作できる
  - `↑` / `k`：上スクロール
  - `↓` / `j`：下スクロール
  - `q`：終了

<!-- omit in toc -->
#### ヘルパーとバージョン情報

- `--help`：`less`の使い方を調べる
- `--version`：`less`のバージョンを調べる

### ファイルの内容を閲覧2

```bash
more <file>
```

- テキストファイルの内容を一画面ずつ表示する
- 操作方法
  - スペースキー：1ページずつ進む
  - エンターキー：1行ずつ進む
  - `b`：前の画面に戻る
  - `q`：終了

<!-- omit in toc -->
#### ヘルパーとバージョン情報

- `--help`：`more`の使い方を調べる
- `--version`：`more`のバージョンを調べる

### ファイルの内容を閲覧3

```bash
head [-rows] <file>
```

- テキストファイルの先頭10行を表示するか、先頭から指定された行数の内容を表示する

<!-- omit in toc -->
#### ヘルパーとバージョン情報

- `--help`：`head`の使い方を調べる
- `--version`：`head`のバージョンを調べる

### ファイルの内容を閲覧4

```bash
tail [-rows] <file>
```

- テキストファイルの末尾10行を表示するか、末尾から指定された行数の内容を表示する

<!-- omit in toc -->
#### ヘルパーとバージョン情報

- `--help`：`tail`の使い方を調べる
- `--version`：`tail`のバージョンを調べる

### テキストファイルを結合

```bash
cat [--option] <file1> <file2> ...
```

- ファイルを結合する、またはファイルの内容をさっと表示する
  - `>`：結合左記ファイルが存在しない場合は新規ファイルを作成し、存在する場合は上書き保存する
  - `>>`：後期のファイルに前記のファイルの内容を追記する
- conCATenate

<!-- omit in toc -->
#### ヘルパーとバージョン情報

- `--help`：`cat`の使い方を調べる
- `--version`：`cat`のバージョンを調べる
