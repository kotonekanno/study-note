## パスとファイル名を操作する

### パスからディレクトリ名を抽出

```bash
dirname <path_name>
```

- パス名からディレクトリ名だけを取り出す
- 結果は標準出力に書き込まれる

### パスからファイル名を抽出

```bash
basename <path_name>
```

- パスからファイル名だけを取り出す
- 結果は標準出力に書き込まれる
- 同じディレクトリ、同じファイル名のファイルが存在するかどうか確認するときに使う

### ファイル名の拡張子を取り除く

1. `basename`
   
   ```bash
   basename <file_name> <.ext>
   ```

   - 指定したファイルから、決まった拡張子を取り除き、標準出力に表示する

2. `expr`
   
   ```bash
   expr <file_name>
   ```

   - 拡張子が未指定の場合、ファイル名の最後の「`.`」の直前までにマッチした部分を取り出して、標準出力に表示する
