## UNIXアカウントの仕組み

### ユーザアカウントの構成

- ユーザ名：システム内で一意でなければならない
- パスワード
- ユーザID（UID）：システム内でユーザを一意に識別するための数値
- ユーザホームディレクトリ：ユーザがログインしたときに作業を開始するディレクトリ

### アカウントの種類

1. rootアカウント
  - UNIXシステムを管理する特別な権限を持つシステム管理者
  - 以下の機能（全ての機能）を使うことができる
    - システムの起動と終了
    - プロセスの管理
    - ユーザの管理
    - ファイルシステムの管理
    - ネットワークの管理
    - システムセキュリティの管理
    - システムのインストールおよび更新管理
    - カーネルのコンフィギュレーション
    - アプリケーションのインストールおよび更新管理
2. システムアカウント
   - システムにある特定のモジュールを操作するためのアカウント
   - システムモジュールをインストールするときに生成
   - 特定のモジュールに対して有効になる
   - 一般ユーザにサービスを提供する
   - 例：apache, backup, daemon, mail, mysql
3. ユーザアカウント
   - 一般の利用者がUNIXを利用するためのアカウント
   - ユーザアカウントに対して、ファイルやディレクトリに関するアクセス権限が指定される
   - ユーザアカウントに対して、システムモジュールに関する利用権限が指定される
   - ユーザアカウント名はユーザ名と同じ


## アカウントを管理する

### アカウントの追加

```bash
useradd [-option] <username>
```

- 新しいユーザアカウントを追加する

<!-- omit in toc -->
#### オプション

- `-d <dir>`：ホームディレクトリを指定する

### アカウントの削除

```bash
userdel [-option] <username>
```

- 既存のユーザアカウントを削除する

<!-- omit in toc -->
#### オプション

- `-r`：ホームディレクトリを削除する

### アカウントの追加（Debian系）

```bash
adduser [--option] <username>
```

- 新しいユーザアカウントを追加する

<!-- omit in toc -->
#### オプション

- `--home <dir>`：ホームディレクトリを指定する

### アカウントの削除（Debian系）

```bash
deluser [--option] <username>
```

- 既存のユーザアカウントを削除する

<!-- omit in toc -->
#### オプション

- `--backup`：ディレクトリにバックアップを取る
- `--remove-home`：ホームディレクトリを削除する

### パスワードの設定

```bash
passwd [username]
```

- ユーザアカウントのパスワードを設定する
- 管理者が他のユーザのパスワードを設定することもできる

### ユーザの切り替え

```bash
su [-option] <username>
```

- ログインし直さずに他のユーザアカウントに切り替える
- substitute user

<!-- omit in toc -->
#### オプション

- `-` / `-l`：ログイン時のスタートアップファイルを読んで、環境変数を再設定する

### 他のユーザの権限でコマンドを実行

```bash
sudo -u <username> <command>
```

- 他のユーザアカウントに切り替えずに、他のユーザの権限を一時的に使用する
- substitute user do
- 必須設定：`sudo`を利用するユーザの設定情報を「`sudoers`」ファイルに追加する

<!-- omit in toc -->
#### `sudoers`の設定

```bash
`visudo`
```

- 対象ユーザに与える権限を追加する

<br>

- 例1：`testuser ALL=(ALL:ALL) ALL`
  - rootを含む全てのユーザと全てのグループの、全てのコマンド実行権限を「`testuser`」に付与する
- 例2：`testuser ALL(testuser2) /bin/mv`
  - 「`testuser2`」の`ls`コマンド、ユーザ「`root`」の`mv`コマンドの実行権限を付与する 


## 環境を設定する

### 概要

1. 環境変数
   - プログラムの挙動を調整するためのパラメータの1種
   - プロセスごとに保持／管理する
2. PS1変数
   - コマンドプロンプトの表示形式を設定する環境変数
   - ターミナルをカスタマイズできる
3. PATH
   - コマンドの保管場所を管理する変数
   - PATHに追加されたコマンドを、パス無しで実行できる
4. シェル変数
   - 現在実行中のシェルだけが持っている変数

### 環境変数

代表的な環境変数

- `PATH`（コマンドサーチパス）：コマンドの保管場所を管理する
- `PS1`：コマンドプロンプトを定義する
- `PWD`：カレントディレクトリを指定する
- `HOME`：ユーザのホームディレクトリを指定する
- `LANG`：使用言語を指定する

### シェル変数

bashシェルの設定ファイル

- `/etc/bashrc`：bashが起動したときに読み込まれるグローバル変数が書かれている設定ファイル
- `/etc/profile`：ログインした際に読み込まれるシェルのグローバル変数が書かれている設定ファイル
- `~/.bash_profile`：ログイン時に飲み読み込まれる、シェルの個人ユーザの環境変数が書かれているファイル
- `~/.bashrc`：ログインした際に読み込まれる、シェルの個人ユーザの環境変数が書かれているファイル
- `~/.profile`：
  - sh実行時に自動的に読み込まれるファイル
  - bash使用時に`~/.bash_profile`がなかった場合だけ、このファイルが読まれる
