## 概要

- 正規表現（Regular expression）
- 文字列のパターンを表す言語
- 用途
  - 検索
  - 抽出
  - 検証

## 構造

- パターン：要素の組み合わせ
- 要素：文字または特殊記号

## 基本要素

### 文字（リテラル）

例：
```
abc
```

### 任意の1文字

```
.
```

- 改行以外の任意の一文字を表す

### 繰り返し（量指定子）

- `a*`：0回以上
- `a+`：1回以上
- `a?`：0回または1回
- `a{n}`：n回
- `a{n,m}`：n〜m回
  - `a{n,}`：n回以上
  - `a{,m}`：m回以下

### 文字クラス（集合）

- `[abc]`：aまたはbまたはc
- `[a-z]`：小文字英字
- `[0-9]`：数字
- `[^abc]`：a, b, c以外

### グループ化

```
(ab)
```

#### バックリファレンス

グループをキャプチャする

- `\n`：n個目のグループ
- `\0`：全体

### OR条件

```
a|b
```

### 位置指定（アンカー）

- `^`：先頭
- `$`：末尾

### エスケープ

特殊文字を普通の文字として扱う

```
\
```

## 要素のショートカット

- `\d`：数字（`[0-9]`）
- `\w`：英数字と`_`（`[a-zA-Z0-9_]`）
- `\s`：空白

## パターン例

<!-- omit in toc -->
#### 数字のみ

```
^\d+$
```

<!-- omit in toc -->
#### メール形式

```
^\w+@\w+\.\w+$
```

<!-- omit in toc -->
#### 英数字6〜12文字

```
^[a-zA-Z0-9]{6,12}$
```
